# Voally downloads

The apps for running a gaming cafe with Voally. Only the files are here; the code is private.

Get them from the latest release, or from the download page.

- **Voally Hub**: runs the cafe on its own Wi-Fi, with or without internet. For a Windows PC, a Mac, or a spare Android phone that stays at the cafe.
- **Voally**: the phone app for the owner and staff (Android).
- **Voally Screen**: the lock screen for Google TV and Android TV.
